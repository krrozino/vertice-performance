# Vértice Performance

Landing page conceitual de uma academia premium, desenvolvida como projeto de portfólio do **cerjo.dev**.

O projeto foi criado para demonstrar desenvolvimento de interfaces modernas, responsivas e orientadas à conversão, com foco em pequenos negócios e profissionais que precisam de presença digital profissional.

## Destaques

- Layout responsivo para desktop, tablet e celular
- Hero com CTA para aula experimental
- Seções de modalidades, estrutura e diferenciais
- Planos e depoimentos
- CTA final e botão flutuante para WhatsApp
- Navegação por âncoras e menu mobile
- SEO básico e estrutura semântica

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS via CDN para prototipação rápida

## Como executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Sobre o projeto

A **Vértice Performance** é uma marca fictícia criada exclusivamente para fins de estudo e portfólio. Nomes, preços, endereço, telefone, métricas e depoimentos apresentados na interface são demonstrativos.

As imagens são carregadas remotamente a partir do Unsplash.
